# TaskFlow - Industrial Task Management

TaskFlow is a robust, responsive task management application designed with a sleek dark industrial aesthetic. Built for efficiency, it leverages modular JavaScript and local storage to provide a seamless workflow management experience.

![TaskFlow Screenshot](https://raw.githubusercontent.com/Fael7s/taskflow/master/screenshot.png)

## 🚀 Live Demo
Check out the live application: [TaskFlow Live](https://fael7s.github.io/taskflow/)

## ✨ Key Features
- **Industrial Dark Theme**: A high-contrast, focus-oriented UI.
- **Persistent Storage**: Uses `localStorage` to keep your tasks safe across sessions.
- **Modular Architecture**: Clean separation of concerns between data, UI, and logic.
- **Fully Responsive**: Optimized for desktop and mobile devices.

## 🛠️ Technical Stack
- **Frontend**: HTML5, CSS3 (Custom Variables), Vanilla JavaScript.
- **Pattern**: Module-based architecture (Storage, Task, UI, App).
- **Persistence**: Web Storage API.

## 📂 Project Structure
- `index.html`: Core structure and entry point.
- `css/style.css`: Industrial theme styling.
- `js/storage.js`: Local storage persistence logic.
- `js/task.js`: Task data model and management.
- `js/ui.js`: DOM rendering and UI updates.
- `js/app.js`: Main controller and event handling.
