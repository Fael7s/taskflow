# TaskFlow

Gerenciador de tarefas com interface inspirada em design industrial e tema dark.

## Estrutura do Projeto
- `index.html`: Interface principal.
- `css/style.css`: Estilização com tema industrial.
- `js/`: Lógica da aplicação dividida em módulos.
  - `storage.js`: Persistência local.
  - `task.js`: Modelos de dados.
  - `ui.js`: Manipulação do DOM.
  - `app.js`: Inicialização e eventos.

## Como usar
Basta abrir o arquivo `index.html` em qualquer navegador moderno.
